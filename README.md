# Insight.info - Website Traffic Analytics

A comprehensive website traffic analytics system that allows website owners to track their visitors, traffic patterns, and user behavior.

## Features

- Real-time visitor tracking
- Detailed traffic analytics
- Country-wise visitor distribution
- System information tracking (browsers, OS, screen resolutions)
- Referrer tracking
- Search query analysis
- Interactive visitor map
- Historical data analysis

## Requirements

- PHP 7.4+
- MySQL 5.7+
- Apache/Nginx web server
- Modern web browser

## Installation

1. Clone the repository
2. Import the database schema from `database/schema.sql`
3. Configure database credentials in `config/config.php`
4. Set up your web server to point to the `public` directory
5. Visit the website and start tracking!

## Usage

1. Enter your domain name on the homepage
2. Copy the provided JavaScript code
3. Add the code to your website's HTML between the `<head>` tags
4. Add the visitor counter div to your website's body section
5. Access your analytics at `https://insight.info/your-domain.com/overview`

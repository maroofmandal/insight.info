---
title: Product analytics overview
description: Choose meaningful events and move from raw activity to product questions.
category: Product analytics
order: 10
---

Start with actions that represent progress: creating a project, inviting a teammate, completing a checkout, or using a core feature. Use clear, stable event names and attach only properties that help answer a known question.

A practical first model includes an acquisition event, an activation event and one retention signal. Once events arrive, inspect users and build a funnel for the important sequence.

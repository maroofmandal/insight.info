title: Google Tag Manager
description: Load the compatible browser script through a custom HTML tag.
category: Install guides
order: 50
---

Create a Custom HTML tag containing the [first-party Insight.info browser script](/docs/sdks/html-script). Replace the project token, keep the host set to `https://insight.info`, trigger it on the appropriate page views, and publish the container.

Preview the container before publishing and confirm one page view arrives. Avoid installing the same tracker directly and through Tag Manager at the same time.

title: Astro
description: Track pages and interactive islands in an Astro project.
category: SDKs

---

Place the HTML script in a shared Astro layout so page visits initialize consistently. For view transitions, listen for Astro navigation completion and send the new path as a page view.

Interactive React islands can use `@vemetric/react`; plain client scripts can call the compatible web SDK.

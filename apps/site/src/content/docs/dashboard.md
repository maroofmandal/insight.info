The dashboard combines headline visitor and event counts with trends, sources, pages, countries, browsers, operating systems and devices.

Use the time control to select a supported period. Filter and search values remain in the URL so a saved or shared view reopens with the same context.

## Public views

When a project is public, its default link uses the project domain:

```text
https://insight.info/example.com?t=24hrs
```

Public views do not expose project settings or private account information.
